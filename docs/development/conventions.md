# Convenzioni di Codice

- **TypeScript**: Abilitato strict mode. Evitare l'uso di `any`; preferire `unknown`.
- **Nomi file**: CamelCase per React components (`ExpenseForm.tsx`), camelCase per utility e repository (`expenseRepository.ts`).
- **Nomi entità**: Coerenti con la lingua italiana di dominio (es. `Contributor`, `IncomeEntry`, `Expense`, `Project`).
- **Valute e Importi**: Trattati sempre come numeri a 2 cifre decimali (`MoneyAmount`).
