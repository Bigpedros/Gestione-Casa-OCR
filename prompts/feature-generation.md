# Prompt Generazione Nuova Feature

Per aggiungere una nuova feature in Gestione Casa:
1. Definire i tipi in `src/types/`
2. Creare/aggiornare lo schema Zod in `src/schemas/`
3. Implementare il repository in `src/repositories/`
4. Creare il service in `src/services/`
5. Aggiungere la vista e i componenti UI in `src/features/`
6. Scrivere i test in `src/tests/`
