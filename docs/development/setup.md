# Guida allo Sviluppo

## Prerequisiti
- Node.js LTS (v20+)
- npm v10+

## Comandi Principali
```bash
# Installazione
npm install

# Avvio Server Dev
npm run dev

# Controllo Tipi
npm run typecheck

# Linting
npm run lint

# Esecuzione Test Unitari e Business Rules
npm run test

# Build di Produzione
npm run build
```
