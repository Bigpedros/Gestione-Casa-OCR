# MANUALE DESIGN SYSTEM UFFICIALE - GESTIONE CASA

Questo documento specifica il Design System definitivo derivato dalle schermate approvate **Home** e **Report**.

## 1. Palette Cromatica Ufficiale
- **Brand Primary**: Indigo `#4F46E5`
- **Sfondo**: Soft Slate `#F8FAFC`
- **Card / Surface**: Pure White `#FFFFFF`
- **Bordi**: Slate `#E2E8F0`
- **Entrate (Income)**: Emerald `#10B981` (Bg `#ECFDF5`, Text `#059669`)
- **Uscite (Expense / Essenziali)**: Rose `#F43F5E` (Bg `#FFE4E6`, Text `#DC2626`)
- **Spese Gestione Casa**: Blue `#3B82F6` (Bg `#EFF6FF`, Text `#2563EB`)
- **Alimentari / Warning**: Amber `#F59E0B` (Bg `#FFFBEB`, Text `#D97706`)
- **Spese Voluttuarie / Casa**: Purple `#8B5CF6` (Bg `#F5F3FF`, Text `#7C3AED`)

## 2. Tipografia
- **Font**: Plus Jakarta Sans / Inter
- **H1 (Titoli pagina)**: 30px, Bold, `#0F172A`
- **H2 (Titoli sezioni)**: 20px, Bold, `#0F172A`
- **Body Large**: 16px, Medium, `#0F172A`
- **Body Secondary**: 14px, Regular, `#64748B`
- **Caption**: 12px, Regular/Medium, `#94A3B8`

## 3. Raggi di Curvatura (Border Radius)
- **Container / Card Grandi**: `24px` (`rounded-3xl`)
- **Action Card / Modal**: `20px` (`rounded-2xl`)
- **Pulsanti / Input**: `12px` (`rounded-xl`)
- **Badge / Pill**: `9999px` (`rounded-full`)

## 4. Componenti Standard
- **SummaryCard**: Card con icona sferica colorata, importo in grassetto, percentuale di variazione e confronto mese precedente.
- **ActionButtonCard**: Card rettangolare con bordo colorato a contrasto morbido, icona illustrata 3D e testo descrittivo.
- **BottomNav**: Barra di navigazione fissa con 5 tab e pulsante d'azione centrale prominente verde.
